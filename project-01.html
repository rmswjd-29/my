01 / PROBLEM

“리뷰는 수천 개였지만,
믿고 판단하기는 어려웠습니다.”

소비자는 구매 전 확신을 얻기 위해 리뷰 탭으로 진입하지만, 쏟아지는 스폰서 리뷰와 단순 평점 나열로 인해 오히려 극심한 정보 피로를 겪고 있었습니다. 결국 사용자는 진짜 후기를 찾기 위해 외부 블로그와 커뮤니티로 이탈하고 있었습니다.

BEFORE STATE // AS-IS FRICTION AUDIT FATIGUE INDEX: HIGH
⚠
정보 과잉 및 신뢰성 결여 (Friction Points)

1. 광고성 5점 만발로 실제 단점 탐색에 12분 이상 소요

2. 단순 키워드 태그만으로는 제품의 치명적 결함을 파악 불가

3. 결국 인앱 리뷰를 이탈하여 포털 검색창으로 이동

02 / RESEARCH

유저 행동 관찰에서 도출한
3가지 핵심 인사이트

INSIGHT // 01 SEARCH PATTERN

광고성 리뷰가 많을수록
외부 탐색이 증가했습니다.

유저는 인앱 리뷰의 순수성을 신뢰하지 못할 때 네이버 블로그나 유튜브 등으로 이탈하여 실제 구매까지의 리드타임이 2.4배 이상 지연되었습니다.

76%
외부 재탐색 경험 유저 비율
INSIGHT // 02 PURCHASE CRITERIA

사용자는 장점보다
단점을 빠르게 확인하고 싶어했습니다.

구매 확신을 방해하는 '나에게 치명적인 결함'이 있는지 먼저 검증한 뒤에야 비로소 결제 버튼을 누르는 방어적 소비 패턴이 지배적이었습니다.

84%
부정적 피드백 우선 필터 선호도
INSIGHT // 03 AI VERIFICATION

AI 요약은 편리하지만
근거가 없어 신뢰하기 어려웠습니다.

자동 생성된 요약 문장 자체는 매력적이나, '어떤 리뷰를 토대로 나온 결론인지' 원문 대조 링크가 없으면 할루시네이션 의심으로 효용이 급감했습니다.

0%
근거 없는 요약에 대한 무조건적 신뢰
03 / DEFINE
CORE DESIGN QUESTION (HMW)
“수많은 리뷰 속에서
신뢰할 수 있는 정보에
더 빠르게 도달하게 하려면?”
필터링의 고도화와 투명한 근거 제시를 통해 리뷰 탐색 시간을 절반으로 단축하는 UX 솔루션을 정의했습니다.
04 / SOLUTION

신뢰와 속도를 회복하는 3단계 설계

SOLUTION 01

신뢰 가능한 리뷰 필터

단순 최신순·별점순을 넘어 ‘한 달 이상 실사용자’, ‘실제 착용 핏 검증’, ‘재구매 고객’ 등 실질적 검증 태그로 한 번에 정제합니다.

Verified Purchase 1-Month Cohort
filter.module / smart-cohort
✓ 한 달 실사용자 (842)
반복 재구매 고객
포토/영상 검증
FILTER IMPACT 스폰서 및 광고성 의심 리뷰 89% 차단
SOLUTION 02

긍정·부정 균형 AI 요약

칭찬 일색의 요약을 배제하고, 장점과 주의해야 할 단점을 동일한 시각적 위계로 대조하여 편향 없는 판단 기준을 세워줍니다.

Balanced Synthesis Bias Elimination
ai.synthesis / balance-ratio
긍정 포인트 (만족 요인)
부정 포인트 (주의 필요)
CRITICAL FACTOR

"사이즈가 반 치수 작게 나왔으므로 한 사이즈 업을 권장합니다."

SOLUTION 03

근거 리뷰 직접 연결

AI 요약 문장의 모든 핵심 문장에 앵커를 달아 클릭 한 번으로 원본 리뷰 문맥과 작성자의 프로필을 즉시 검증할 수 있습니다.

Evidence Linking Transparency
evidence.anchor / instant-verify

“배송 중 파손 없는 포장 상태 [리뷰 #142]”

VERIFIED SOURCE EXCERPT

“박스 안에 에어캡이 두 겹으로 싸여 있어서 파손 걱정 없었습니다.”

05 / FINAL DESIGN

신뢰와 직관을 담은 최종 인터페이스

복잡한 리뷰 데이터를 한눈에 구조화하고, 유저가 스스로 검증하고 확신할 수 있는 완결된 화면 흐름입니다.
